Refresh: ../setup.sh  (sources are gitignored; only this file is committed)

Build (from this directory):
  chpl --fast -suseLCG=false ra.chpl -o ../out/ra_chpl
  chpl --fast -suseLCG=false ra-atomics.chpl -o ../out/ra_chpl_atomic

-suseLCG=false selects the HPCC LFSR so the stream matches ra.h.
Run with -nl 1 for the SMP pair (CC smp / smp-atomic). Multi-locale
is `../compare_dist.sh`: -nl N when CHPL_COMM is not none, against
CC ra_dist.ccs. On one locale ra.chpl is Figure 5.
