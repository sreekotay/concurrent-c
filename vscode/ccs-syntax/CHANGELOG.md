# Changelog

## 0.4.2

First Visual Studio Marketplace release.

- Syntax highlighting for `.ccs`, `.cch`, and `.shcc`
- Concurrent-C `@` keywords, result unwrap, UFCS, type sugar, duration literals
- `@string` templates, `@emit` bodies, `@grammar` fences
- Language configuration (comments, brackets, auto-closing pairs)
- Breakpoint support for the Concurrent-C language id
