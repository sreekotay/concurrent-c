Branch: per-thread token batches; like-for-like contended rows.
Previous receipt: arena_lifetime_20260904_owned_checkpoint.txt.

What changed:
- cc_slice_gen_birth claims one 64-token word per thread (one fetch_add on
  the shared cursor, one CAS that sets the word's free bits) and hands
  tokens out from thread-local state. A birth touches no shared line; a
  kill is still one CAS on the token's word. Tokens start at 64.
- Three contended rows added to both benches: one arena per thread (alloc
  with reset/4096; alloc + release_sized), which is the shape a thread-
  caching malloc is measured in, and the raw 4-thread CAS bump on one word,
  identical code on both sides, which is the physics floor the shared rows
  should be read against. The shared-arena rows swing 60 to 130 ns run to
  run on this VM; the floor is stable near 40.
