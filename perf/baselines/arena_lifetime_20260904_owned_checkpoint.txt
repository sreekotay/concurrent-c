Previous receipt: arena_lifetime_20260904_calllocal.txt.

What changed:
- cc_arena_checkpoint_local / cc_arena_restore_local: the alloc_local
  contract (one owner). No meta lock; restore is a plain store of the slab
  word; the mark index rides in the handle so restore does not search.
  @scratch lowers to this pair.
- Epochs come from a per-host block of 256 (one fetch_add on the global
  counter per block) instead of one fetch_add per checkpoint.
- The nested-mark array lives beside the host for heap hosts (past the L1
  end in the same malloc), promoted children (after the attach node) and
  cc_arena_stack frames (a frame array), flagged MARKS_FIXED. It is no
  longer re-carved from the slab after every restore to depth 0, which was
  a CAS plus a lock pair per nested iteration.
- The shared cc_arena_restore has an inline fast path (mark still on the
  host, nothing promoted, armed inside, or attached since): one lock pair
  and one CAS; everything else goes to the out-of-line slow path.
